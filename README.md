# Prime Auto Boutique Ph Website

Static multi-page site for **Prime Auto Boutique Ph** (Marikina) — HTML, CSS, and vanilla JS with an iOS 26–inspired Liquid Glass UI.

## Open locally

Open [`index.html`](index.html) in Chrome, Edge, or Firefox.

```bash
cd "Prime Auto Boutique Ph"
python -m http.server 5176
```

Then visit http://localhost:5176
